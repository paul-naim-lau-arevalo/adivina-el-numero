# Adivina el número

Juego de consola hecho en Python para adivinar un número secreto.

## ¿Cómo jugar?

1. Elije una dificultad: fácil (1–10), medio (1–20) o difícil (1–50).
2. Ingresa un número para intentar adivinarlo.
3. El programa te dice si el número secreto es mayor o menor.
4. Tienes 5 intentos. Al terminar, puedes jugar otra vez.

## Ejecutar

Con Python 3 instalado, abre la terminal en esta carpeta y ejecuta:

```bash
python3 main.py
```

En Windows, también puedes usar `py main.py`.

## Archivos

- `main.py`: programa principal.
- `README.md`: instrucciones para correr programa.
